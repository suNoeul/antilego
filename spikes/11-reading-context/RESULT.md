# Spike 11 — 지명에서 본문으로, 삼손 이야기 데모

2026-09-30 · Codex · 기준 HEAD `fb28caa`.

**판정: 로컬 구현·자동 검증 통과, Snow의 시각 판정 대기.** 아직 커밋·푸시·웹 배포하지 않았다.
Snow가 지명 카드의 구절 연결, 삼손 데모, 간결한 디자인, 배포 전 자동 검사와 점진적 코드 분리를
요청했다. 이 명시적 요청에 따라 UI와 배포 설정까지 수정했다.
방향과 제외 범위의 정본은 [Notion ADR-30](https://app.notion.com/p/3ebd1323042d810da48fcce98c902f86)에 두며,
이 문서는 구현·검증 근거를 기록한다.

## 적용

- 지명 카드에 현재 장의 등장 절을 표시한다. 절을 누르면 본문을 보이게 하고 해당 절의 다른 지명을
  함께 표시한다. 같은 장에서 지명만 바꾸면 기존 지도 시점을 유지한다.
- `다른 장에서도 찾아보기`는 기본 접힘이며 처음 펼칠 때만 역색인을 요청한다.
  목록은 12개씩 더 보여 준다. 실패해도 본문은 유지하고 재시도할 수 있다.
- 탐색 중에는 첫 읽던 장·스크롤·선택·지도 시점을 임시로 기억해 돌아갈 수 있다.
  재실행 후 특정 절을 복원하는 기능이 아니며 저장소에 새 읽기 위치를 기록하지 않는다.
- 사사기 13–16장 제목 아래 `삼손 이야기 · 8장면 따라 읽기`를 둔다.
  사용자가 이전/다음으로 이동하며 기존 본문과 지명 대표점을 확인한다. 자동 재생하지 않는다.
- 긴 시대 설명과 지도 안내·출처는 접고 지명·구절 연결을 먼저 보여 준다.
  기존 팔레트를 유지하고 글자 크기·여백·정보 순서로 구분한다. 돌아가기 안내는 본문 위의 얇은 행이다.
  모바일 데모에서는 장면 조작부와 지도 버튼이 아래 시트 안에 들어오도록 지도 높이를 조정한다.
- 이동한 구절/복귀한 장을 보조 기술에 알린다. 키보드 포커스, 다크 모드, 동작 줄이기 및
  지형 실패 시 간단 지도 전환 경로를 유지한다.

거리 비교, 절 단위 재실행 복원, 앱·PWA·오프라인 기능은 추가하지 않았다.

## 삼손 장면의 근거

| 장면 | 근거 | 기존 지명 |
|---|---|---|
| 소라의 마노아 집 | 삿 13:2 | 소라 |
| 소라와 에스다올 사이 | 삿 13:25 | 마하네단·소라·에스다올 |
| 딤나에 내려가다 | 삿 14:1 | 딤나 |
| 아스글론 | 삿 14:19 | 아스글론 |
| 레히에 이르다 | 삿 15:14 | 레히 |
| 소렉 골짜기 | 삿 16:4 | 소렉 골짜기 |
| 가사에 붙잡혀 가다 | 삿 16:21 | 가사 |
| 다시 소라와 에스다올 사이 | 삿 16:31 | 소라·에스다올 |

전체 생애의 모든 사건을 수록한 것이 아니다. 새 좌표·이동 경로선·묘소 위치를 추정하지 않았다.
마지막 장면에도 묘소 좌표가 아니라는 안내를 표시한다. 세 정적 역본에서 각 장면의 대표 지명이
실제로 연결돼 있는지 검사했다.

## 구조와 데이터

- `web/reading-context.js`: 같은 절의 지명·등장 절·다른 장의 참조 계산, 장면 자료, 임시 왕복 상태.
- `web/context-panel.js`: 지명 카드·이야기 조작부·접힌 시대 설명의 DOM 표시.
- `web/context-panel.css`: 해당 UI의 시각 계층과 반응형 스타일.
- `web/app.js`: 기존 장/역본 라우팅과 두 모듈의 연결만 담당한다. 전체 재작성은 하지 않았다.
  늦게 도착한 데이터나 이전 이동의 프레임이 새 이동을 덮지 않도록 요청 표식을 확인한다.
- `web/data/place-refs.json`: 기존 개역한글·KJV·BSB의 지명 연결로 재현한 역색인, 325,877 bytes.
  본문을 복제하지 않는다. ESV 본문은 저장/색인하지 않으며 ESV에서 사용할 때는 개역한글
  지명 색인 기준임을 명시한다. 열린 앱 안에서 색인 요청을 공유한다.
- `build.mjs`: 기존 배포 자료에서 역색인을 재생성하고 아래 두 매핑을 반영한다.
  `--check`는 파일을 쓰지 않고 결과가 달라지면 실패한다. 전체 본문 빌더를 실행한 뒤에도
  이 생성기를 실행해 색인을 갱신해야 한다. 새 외부 자료·라이선스는 도입하지 않았다.

본문 대조 중 확인한 기존 자동 매핑 오류 두 건을 수동 보정했다.

| 지명 ID | 잘못 연결된 낱말 | 수정한 연결 | 근거 |
|---|---|---|---|
| `a339971` | 들릴라라 | 소렉 골짜기 | 삿 16:4 |
| `a601121` | 내어던지고 | 라맛 레히 | 삿 15:17 |

`places.ko.overrides.json`을 정본으로 배포용 이름과 두 장의 연결 구간만 수정했다.
장소 좌표와 **성경 본문 문자열은 변경하지 않았다**. 수정 전 `[절 번호, 본문]` 배열의 SHA-256을
검사에 고정했다.

- 사사기 15장: `b86a775be7858979746ec6ee4ddfc2493bb09edd9bb7d85fab57df90296f71d4`
- 사사기 16장: `c409264a8ffc3571f8488e9912ba466774cb7fbd4dcbca3133a3f1dce1ca2e1e`

## 배포 전 검사 연결

Pages 작업을 `verify → build → deploy` 순서로 연결했다. 검사 실패 시 빌드·배포하지 않는다.
PR은 읽기 권한으로 검사만 실행하고 웹을 배포하지 않는다. 새 모듈의 import도 기존 배포 버전 치환에
포함했다. 원격 Actions에서의 실제 실행은 아직 하지 않았다.

로컬과 CI는 같은 검사 진입점을 사용한다. 기본 검사는 외부 폰트/API/DEM 응답을 대체하므로
인터넷 지형 서비스의 상태가 배포 판정을 좌우하지 않는다. 실제 DEM 검사는 별도 옵션이다.
검사는 자체 임시 Chrome 프로필과 포트를 사용하며 사용자의 브라우저를 종료하지 않는다.

## 검증

macOS Chrome 헤드리스, 데스크톱 1400×950 / 모바일 390×844, 밝은/어두운 테마에서 확인했다.

| 기본 검사 | 통과 |
|---|---:|
| 장 이동 순수 계산 | 2,656 |
| SVG 계산 | 8 |
| 지형 계산 | 26 |
| 배경 이름 계산 | 53 |
| 새 구절 관계·장면·본문 불변 | 78 |
| 배포 YAML 계약 | 12 |
| 새 기능 브라우저 | 64 |
| 기존 접근성 | 76 |
| 기존 피커·역본·실패 처리 회귀 | 275 |
| 합계 | **3,248** |

별도로 실제 DEM을 사용하는 지명 비교 44개, 지형 33개, 배경 이름 54개(총 131개)도 통과했다.
새 기능 브라우저 및 기존 회귀에서 미처리 JS 예외·console.error 0건.
문법 검사, 생성 결과 불변 검사와 `git diff --check`도 통과했다.

- 처음엔 모바일의 고정 상단바가 이야기 진입점의 클릭을 가리고, 이전 패널 스크롤이 데모 조작부를
  숨기는 문제가 있었다. 스크롤 여백과 장면 진입 시 패널 위치 초기화로 수정하고 실제 클릭으로 재검사했다.
- 마지막 화면 점검에서 모바일 데모의 지도 버튼이 시트 아래에 걸리는 문제를 수정하고 가시성 검사를 추가했다.
- 다른 장 탐색/첫 자리 복귀, 여덟 장면과 이전/끝내기, 닫힌 패널에서 특정 절 선택,
  색인 실패/재시도, 영문 역본, 재실행 시 임시 상태 미복원까지 검사했다.
- 인앱 브라우저에서도 실제 지형을 켠 채 삼손 장면의 같은 장/다른 장 전환을 확인했다.
- 임시 화면 기록: `/tmp/antilego-reading-context-shots/` 및 `/tmp/antilego-reading-terrain-shots/`.
  스크린샷·브라우저 프로필은 저장소에 넣지 않는다.

### 재현

저장소 루트에서 실행한다. Node와 Ruby, Chrome이 필요하다. Chrome 경로는 `CHROME_BIN`으로 지정할 수 있다.

```sh
# 기본: 순수 함수·자료·배포 계약 + 새 기능·접근성·기존 브라우저 회귀
node spikes/11-reading-context/verify/run.mjs

# 브라우저 없이 빠른 검사
node spikes/11-reading-context/verify/run.mjs --unit

# 별도: 실제 DEM을 사용하는 지형 회귀(인터넷 필요)
node spikes/11-reading-context/verify/run.mjs --terrain

# 기존 자료를 변경했을 때 역색인 재생성
node spikes/11-reading-context/build.mjs
```

8765 포트의 기존 서버는 같은 프로젝트인지 확인 후 재사용하고 종료하지 않는다.
서버가 없으면 검사 중에만 로컬 정적 서버를 열고 종료한다.

## 남은 확인

- Snow의 실제 읽기 흐름/시각 판정과 커밋·배포 승인.
- 실물 Galaxy S24+의 터치·성능·글자 가독성. 모바일 크기 검사는 실물 검사를 대신하지 않는다.
- 최초 원격 CI 실행과 배포 후 확인. 현재 통과 수치는 로컬 검사 결과다.
- 다른 장 목록은 기존에 지명으로 연결된 구절의 색인이며 성경 전체의 모든 지명 용례를 보증하지 않는다.
  이번 데이터 검토는 삼손 데모와 발견한 두 오류에 한정되며 전체 자동 매핑 감사를 수행한 것은 아니다.
