## 무엇을 바꿨나

### 1. 밑줄 제거

`.place` 에서 `border-bottom: 1px dotted` 와 `:hover { border-bottom-style: solid }` 를 걷어냈다.
남은 것은 **색(`--accent`)** 하나뿐이다. hover 는 아주 옅은 배경(`--hl-soft`, alpha .07),
선택은 기존대로 배경 하이라이트(`--hl`, alpha .13). `text-decoration` 은 명시적으로 `none`.

### 2. 지도가 하나로

없앤 것 — `aside.side` + `#side-card`(스티키 사이드 카드), `.inline-card`(모바일 인라인 카드),
`<details id="chapmap">`("▸ 이 장의 지도"), `#modal` 전체("크게 보기"). `app.js` 의 `makeCard`,
`openModal`, `closeModal`, `wide()`, `state.selV` 도 같이 사라졌다.

남은 것 — `#panel` 하나. 폭에 따라 성격만 바뀐다.

| 폭 | 모양 | 본문 |
|---|---|---|
| ≥ 1200px | 오른쪽 서랍 400px | `body { margin-right: 400px }` 로 **밀려난다** |
| 900–1199px | 같은 서랍이 **덮는다** | 뒤에 가림막 `#scrim` (누르면 닫힘) |
| < 900px | 아래에서 올라오는 시트 55vh, 위에 드래그 손잡이 | 그대로. 시트를 내리면 다시 읽힌다 |

여는 길은 둘이다. **플로팅 버튼**(오른쪽 가장자리 세로 중앙 / 모바일은 오른쪽 아래, 글자 `지도`↔`닫기`,
`aria-expanded`)과 **본문의 지명 클릭**. 지명을 누르면 패널이 없던 상태에서도 열리면서 그 지명이 강조된다.
패널이 열리면 버튼은 패널 가장자리로 옮겨 붙는다(`right: 400px` / 시트 위 12px).

패널 안은 위에서 아래로: 지도 SVG(4:3, 최소 240px) → 확대 버튼 `+` `−` `⟲`(지도 오른쪽 아래) →
지명 블록(한글 18px 굵게 / 영문 12px 회색 / "이 장에서 N회 · 성경 전체 M회") →
**빈 `#era-caption`**(Spike 03 자리, 비어 있으면 `display:none`) → 출처 한 줄.

상태는 `localStorage['panel']` 에 남는다(try/catch). `Esc` 로 닫힌다. 장을 옮겨도 상태는 유지되고
새 장의 Scene 으로 다시 그린다.

### 3. 확대·축소

`renderScene(svgEl, scene, layers, tokens, **view**)` — 다섯 번째 인자가 늘었다.
`view = { z, px, py }`, 기본 `{1, 0, 0}` = Spike 01 과 같은 그림. `clampView`·`zoomAt`·`BASE_VIEW`·
`W`·`H`·`ZOOM_MIN`·`ZOOM_MAX` 를 같이 export 한다. 함수는 여전히 순수하다(fetch·전역 상태 없음).

**`<g transform>` 을 쓰지 않았다.** 확대할 때마다 좌표를 **다시 계산**해서 그린다. 그래서

- 점 반지름(3 / focus 5)과 글자 크기(12 / focus 14)가 viewBox 단위로 고정 → 화면에서 항상 같은 크기
- 라벨 겹침 판정이 **배율마다 화면 공간에서 다시** 돈다 → 1× 에서 숨었던 라벨이 확대하면 되살아난다 (LOD)
- 화면 밖(여유 8px)으로 나간 점·라벨은 아예 그리지 않는다

조작: 휠(커서 기준) · 드래그(포인터 1개) · 핀치(포인터 2개, 중점 기준) · 더블클릭(1.8배) ·
`+` `−`(1.6배씩) · `⟲`(scene bbox 로 복귀). 배율은 1×–8× 로 자르고, 이동은 내용이 화면 밖으로
완전히 빠지지 않게 자른다. 장이 바뀌거나 선택이 바뀌면 자동으로 초기화된다.

`+` `−` 는 **화면 한가운데가 아니라 지명이 모인 자리**(선택된 지명, 없으면 이 장 지명들의 무게중심)를
기준으로 확대한다. 이유는 아래 "판단" 1번.

### 확대·축소 (여호수아 10장, 장소 20곳)

`+` 버튼과 같은 경로(`zoomAt(view, ...anchor(), f)`)로 배율을 정확히 맞춰 잰 값:

| 배율 | `text` 개수 | `circle` 개수 | `font-size` | `r` |
|---:|---:|---:|---|---|
| **1×** | **8** | 20 | 12 | 3 |
| **3×** | **10** | 12 | 12 | 3 |
| 8× (상한) | 6 | 6 | 12 | 3 |

- **1× → 3× 에서 라벨이 8 → 10 으로 늘었다.** 1× 에서는 20곳 중 8곳만 라벨을 얻지만
  3× 에서는 화면에 남은 12곳 중 10곳이 라벨을 얻는다. 확대하면 겹침이 풀린다는 뜻이다.
- **글자 크기와 점 반지름은 모든 배율에서 12 / 3 으로 같다.** 화면에서 커지지 않는다.
- 배율 상한이 실제로 걸린다: 8× 에서 다시 5배를 요청해도 `z = 8` 그대로.

조작별 실측:

| 조작 | 관측값 | 판정 |
|---|---|:--:|
| 휠 (`deltaY = -240`, 지도 중앙) | `z` 1 → **1.696** | ✅ |
| 드래그 (왼쪽 60px · 위 30px) | `px` −111 → **−163**, `py` −83.2 → **−109.3** | ✅ |
| `⟲` | `{ z: 1, px: 0, py: 0 }` | ✅ |
| `−` 비활성 조건 | `z ≤ 1` 에서 `[disabled]`, `z ≥ 8` 에서 `+` 가 `[disabled]` | ✅ |

렌더 시간(여호수아 10장, Natural Earth 3레이어, 20회 평균): **1× 3.13ms · 3× 2.00ms · 8× 2.10ms**.
확대·드래그마다 통째로 다시 그리는 설계인데도 목표 50ms 에 한참 못 미친다.

## 판단 (스펙에서 정하거나 벗어난 것)

1. **`+` `−` 의 기준점을 화면 한가운데가 아니라 "지명이 모인 자리"로 했다.**
   한가운데 기준으로 처음 만들었더니 여호수아 10장에서 라벨이 **1× 8개 → 2.56× 7개 → 4.1× 4개**로
   *줄었다*. 가데스바네아가 남쪽으로 끌어당긴 bbox 의 한가운데가 지명이 없는 자리여서, 확대할수록
   지명들이 화면 밖으로 밀려난 것이다. 기준을 선택된 지명(없으면 이 장 지명들의 무게중심)으로 바꾸니
   **1× 8 → 3× 10 → 8× 6** 이 됐다. 확대의 목적이 "작은 지명을 더 보는 것"이므로 이쪽이 맞다.
   휠·핀치·더블클릭은 스펙대로 커서 기준 그대로다.
2. **라벨을 viewBox 밖으로 나가게 두지 않고, 화면 밖 점·라벨은 아예 그리지 않는다.**
   Spike 01 C 의 단언 17("라벨이 viewBox 밖으로 나감 0건")을 확대 상태에서도 지키기 위해서다.
   대신 이 컬링 때문에 아주 크게 확대하면 라벨 수가 다시 줄어든다(8× 에서 6개). 정상이다 —
   화면에 지명이 6곳밖에 안 남았기 때문이다.
3. **`<g transform>` 대신 매 프레임 재계산.** 스펙이 둘 다 허용했다. 재계산 쪽이 라벨 배치와
   점 크기를 화면 공간에서 그대로 다룰 수 있어 LOD 규칙이 한 군데로 모인다. 비용은 2~3ms 다.
4. **데스크톱에서 본문을 미는 방법은 `body { margin-right }`.** `.cols` 에 `padding-right` 를 주면
   `max-width: 1040px; margin: 0 auto` 와 겹쳐 본문이 패널 밑으로 들어간다. `body` 마진은 상단바까지
   같이 밀어 줘서 화면이 한 덩어리로 좁아진다. `position: fixed` 인 패널은 영향받지 않는다.
5. **모바일 시트 손잡이는 아래로 50px 이상 끌면 닫힌다.** 스펙은 "드래그 손잡이"만 요구했다.
   끄는 동안 시트가 따라 내려가는 애니메이션은 넣지 않았다(놓을 때 판정만).
6. **`window.__antilego = { state, drawMap, setPanel, anchor }`.** 배율을 정확히 3× 로 맞춰
   라벨을 세려면 앱 내부 상태에 닿아야 했다. 앱 동작에는 관여하지 않고, Spike 03 검증에도 쓸 수 있다.
7. **아이콘.** 스펙이 허용한 `+` `−` `⟲` 를 확대 버튼에 썼다. 나머지는 그대로 `‹ › ☾` 이고,
   `▸` 는 접힌 지도와 함께 사라졌다. 플로팅 버튼과 닫기는 글자다.
8. **`renderScene` 반환값이 `svgEl` 에서 `{ view, labels, shown, project }` 로 바뀌었다.**
   `project(lon, lat)` 는 현재 view 기준 viewBox 좌표를 준다(위 1번에 필요). 반환값을 쓰던 곳은 없었다.

## 남은 것 / 알려진 결함

- **패널 아래쪽이 비어 있다.** 데스크톱 400×(화면 높이) 서랍에 지도 4:3(약 370×278)과 지명 세 줄뿐이라
  아래 절반이 빈다. `#era-caption` 이 채울 자리이고(Spike 03), 그 전까지는 허전하다.
- **태블릿(900–1199)에서 패널이 본문을 덮는다.** 스펙이 지정한 동작이지만, 1000px 에서 본문 오른쪽
  약 235px 이 가려진다. 1200 문턱을 낮출지는 Snow 판단.
- **8× 상한이 레반트 안쪽 장에서는 넉넉하지만 사도행전 27장처럼 넓은 장에서는 부족할 수 있다.**
  bbox 가 지중해 전체라 8× 여도 도시 하나 규모로는 못 들어간다. 필요하면 상한을 올리면 되지만
  Natural Earth 1:10m 단순화(0.002°) 한계가 먼저 보일 것이다.
- **핀치 확대는 실제 기기에서 확인하지 못했다.** 헤드리스에서 포인터 두 개를 흉내 내는 경로는
