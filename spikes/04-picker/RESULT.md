## 무엇을 바꿨나

### 1. 상단바 — 셀렉트 두 개 → 위치 버튼 하나

`<select id="sel-book">` · `<select id="sel-chapter">` 와 `fillBooks()` · `fillChapters()` ·
`change` 바인딩 · `select { … }` CSS 를 통째로 걷어냈다. 저장소에 `sel-book`/`sel-chapter`
문자열은 한 군데도 남아 있지 않다.

남은 것은 `#loc` 버튼 하나다 — `사사기 9장` + 아주 작은 쉐브론(`▸` 를 90° 돌린 것.
아이콘을 `‹ › ☾ ▸ × ←` 로 제한한 규칙을 지키려고 새 글리프를 들이지 않았다).
클릭·`Enter`·`Space` 로 열리고, `aria-haspopup="dialog"` · `aria-expanded` 로 상태를 알린다.

### 2. 성경 찾기

한 벌의 DOM(`#picker`)이 폭에 따라 성격만 바꾼다.

| 폭 | 모양 |
|---|---|
| ≥ 900px | 상단바 아래(`top: 56px`) 가운데 정렬 팝오버. `min(880px, 100vw − 32px)`. 3열이 한꺼번에 |
| < 900px | 전체 화면 시트(`inset: 0`, `z-index: 60`). `data-step` 으로 권 → 장 → 절 한 단계씩 |

- **성경권**: `group` 별 섹션(10종, 정경 순서) · 한 줄 = **약어 칩 + 한글 + 영문(12px 옅게)**.
  칩은 폭 32px 고정, 반지름 6px, **구약 파랑 · 신약 빨강**.
- **장**: 숫자 격자. 누르면 **바로 옮긴다**(`#Book.N`). 피커는 열린 채로 있고 절 열이 찬다.
- **절**: 그 장의 절 수만큼. 누르면 **스크롤 + 2초 표시** 후 닫는다. **해시는 건드리지 않는다.**

열 머리는 `성경권` / `장 · 창세기` / `절 · 창세기 12장` 이다. 커서(↑↓)와 선택이 다를 수 있어서
숫자가 어느 권의 것인지 열 머리에 옅게 붙였다 (스크린샷을 보고 더한 것).

### 3. 검색 — 초성 · 영문 · 장절

`parseQuery(raw)` 가 **끝에 붙은 숫자만** 장·절로 가른다. 그래서 `1co` 의 `1` 은 글자 쪽에 남는다.

| 입력 | `{text, ch, v}` |
|---|---|
| `삿 9:3` | `{"삿", 9, 3}` |
| `9:3` · `9 3` · `9.3` | `{"", 9, 3}` |
| `고전 9` | `{"고전", 9, null}` |
| `9` | `{"", 9, null}` |
| `1co` · `gen` | `{"1co"·"gen", null, null}` |

글자 쪽은 한글이 섞여 있으면 한글 길, 아니면 영문 길이다.

- **한글**: `koPrefix(q, target)` 가 한 글자씩 본다. 낱자 자음(`ㄱ`)이면 그 자리 글자의 **초성**과,
  완성 음절(`사`)이면 **그 글자 그대로** 비교한다. 초성은 `U+AC00` 기준 `(code − 0xAC00) / 588`
  로 19개 표에서 꺼내고 쌍자음은 홑자음으로 접는다(`ㄲ`→`ㄱ`).
  **약어와 한글 이름 둘 다**에 대고 재며, 결과는 두 쪽을 합쳐 **정경 순서**로 돌려준다.
- **영문**: `en` 과 OSIS `id` 에 대한 대소문자 무시 접두 일치. `en` 은 공백·기호를 지우고 잰다
  (`1 Corinthians` → `1corinthians`, 그래서 `1co` 가 맞는다).
- 정확히 한 권으로 좁혀지면 그 권을 **골라 둔다**(장 열이 찬다). **옮기지는 않는다.**
- 일치가 없으면 `일치하는 책이 없습니다` (옅은 글자).

### 4. 모바일 초성 칩

`ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ` 14개. 가로로 넘치면 **그 줄만** 스크롤된다
(`overflow-x: auto`, 페이지는 360px 그대로). 누르면 `ㄱ ×` 로 바뀌고, 다시 누르면 풀린다.
칩과 입력은 **곱해진다** — 칩 `ㄱ` + `고` → 고린도전서·고린도후서.

### 5. 데이터 — `index.json` 에 `en` · `group`

```json
{"id":"Judg","ko":"사사기","abbr":"삿","en":"Judges","testament":"OT","group":"역사서","chapters":21}
```

분류 10종(구약 5 · 신약 5)은 정경 순서대로 `율법서`(5) `역사서`(12) `시가서`(5) `대선지서`(5)
`소선지서`(12) `복음서`(4) `사도행전`(1) `바울서신`(13) `공동서신`(8) `요한계시록`(1) = 66.

정본 표는 `build.py` 의 `EN_NAMES` · `BOOK_GROUPS` 다. 전체 재생성이 `data/raw/` 와 `shapefile`
을 요구해서, 이번에는 `spikes/04-picker/rebuild_index.py` 로 **index.json 만** 다시 썼다.
이 스크립트는 build.py 를 실행·import 하지 않고 `ast` 로 표만 꺼내 온다 (README 참고).
두 번 돌려 md5 동일(`bb232eb8d41029e10a532cc118cdc0d8`) — 멱등이다.

## 벗어난 점 / 남은 것

- **`ㅅㅅ` 는 두 권이다** — 사사기(`ko` 사·사)와 **사무엘상**(`abbr` 삼·상). 스펙이 물어본
  "그 밖의 ㅅㅅ 책"이 이것이다.
- **`ㄱ` 의 순서**는 정경 순서(겔·고전·고후·갈·골·계)이지 스펙 본문에 나열된 순서가 아니다.
  집합은 같다.
- **초성 매칭은 약어와 한글 이름을 합친다.** 스펙의 "abbr first, then on ko" 를 "약어 쪽을
  먼저 재고 한글 이름 쪽도 재어 합친다"로 읽었다. "약어에서 나오면 한글은 안 본다"로 읽으면
  `ㅅㅅ` 가 사무엘상 하나가 되어 스펙의 기대(`ㅅㅅ` → 사사기)와 어긋난다.
- **커서와 선택은 다르다.** `↑`/`↓` 는 커서(`.bk.hi`, 1px 테두리)만 옮기고 `Enter` 가 고른다.
  선택(`aria-selected`, 배경)은 클릭·`Enter`·**정확히 한 권으로 좁혀졌을 때**만 바뀐다.
  스펙대로다. 그래서 여러 권이 걸린 상태에서는 장 열이 **커서와 다른 권**의 것일 수 있어,
  열 머리에 `장 · 창세기` 처럼 권 이름을 옅게 붙였다 (스펙에 없던 추가).
- **모바일 2·3단계에서 초성 칩 줄을 감춘다.** 그 줄은 권 목록만 거르기 때문이다. 검색 입력은
  남겨 뒀다 — 시편 119장처럼 긴 책에서 `119` 를 치는 게 스크롤보다 빠르다.
- **쉐브론은 `▸` 를 90° 돌린 것**이다. `▾` 를 쓰면 아이콘 제한 목록(`‹ › ☾ ▸ × ←`)을 벗어난다.
- **검색 돋보기 글자(`검색`)는 넣지 않았다.** placeholder 가 이미 무엇을 치는지 말한다.
- **모바일에서는 입력 칸에 자동 포커스하지 않는다.** 열자마자 키보드가 올라와 칩 줄과 목록을
  덮기 때문이다. 스펙도 자동 포커스를 데스크톱에만 걸었다.
- **바깥 클릭은 `mousedown` 으로 받는다.** 터치는 모바일 전체 화면이라 바깥이 없다.
- **`aria-modal="true"` 를 걸었지만 포커스 트랩은 `Tab` 순환만이다.** 스크린 리더로 실제
  읽어 보지는 않았다.
- **절 수는 장 JSON 을 받아 센다.** 이미 읽고 있는 장이면 `state.data` 를 그대로 쓰고,
  다른 장은 한 번 받아 `Map` 에 캐시한다. `index.json` 에 절 수를 넣지는 않았다
  (66권 × 1,189장 = 파일이 서너 배가 된다).
