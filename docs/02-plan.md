## Spike 00 — 한글 지명 매핑 (다음 작업)

**검증할 질문:** 영문 지명 → 한글 지명 매핑을 실용 수준으로 만들 수 있는가?
이게 안 되면 이 프로젝트는 성립하지 않는다. 그래서 여기부터 한다.

1. 데이터 3종 내려받기 → `data/raw/`
   - OpenBible 지오코딩 (장소 + 좌표 + 구절 목록)
   - STEPBible TIPNR (고유명사 개별 ID, 동명이지 구분)
   - 개역한글 본문
2. Wikidata에서 한국어 레이블 자동 수집 → 커버리지 측정
3. 구절 제약 기반 후보 추출로 빈 칸 메우기
4. 등장 빈도 상위 장소부터 수동 검증

**성공 기준:** 성경 전체 지명 *언급 횟수* 기준 80% 이상이 한글 지명과 연결됨
(장소 개수 80%가 아님 — 한 번만 나오는 희귀 지명은 뒤로 미뤄도 됨)

**산출물:** `data/derived/places.ko.json` + 커버리지 리포트

## Spike 01 — 읽기 UI 프로토타입

**검증할 질문:** 본문 옆 미니맵이 실제로 읽기 흐름을 덜 끊는가?

- 한 장(chapter)만 대상. 후보: 여호수아 10장, 사도행전 27~28장(바울의 항해),
  또는 창세기 12장(아브라함의 이동) — 지명이 조밀하고 이동 경로가 있는 장
- 정적 HTML 한 장으로 충분. 프레임워크 없이.
- 양식화 SVG 맵 손으로 그려서 붙임 (자동 생성은 나중에)
- 판정: 본인이 실제로 그 장을 읽어보고 판단

## Spike 02 — 지도 렌더링 파이프라인

**검증할 질문:** 양식화된 맵을 장면마다 자동 생성할 수 있는가, 아니면 다 손으로 그려야 하는가?

- 좌표 → 단순화된 SVG (해안선/강/산은 저해상 자연지물 데이터에서)
- 장면 bbox 자동 계산 (그 장에 나오는 지명들을 감싸는 범위)
- 손그림이 불가피하다면 범위를 어디까지 줄일지 여기서 결정
