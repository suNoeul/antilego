# 컨셉

## 출발점 (노션 기록에서)

> 성경에는 각 시대별 많은 지역 이름들이 등장함. 낯선 이름들을 볼 때면 말씀을 읽을 때
> 집중을 방해함. (글 내용이 머릿속에 잘 들어오지 않는다!) 각 내용들과 관련된 지도를
> 성경 구절에 맞추어 연결지어 단순하고 보기 귀여운 UI 형태로 구현 하면 좋을 것 같다. [24.08.08]

원 기록: 노션 `Personal / 아이디어 / BrainStorming` (24.08.08 작성, 25.05.22 VR 아이디어 추가)

## 문제 정의

읽기 흐름이 끊기는 지점은 "지도가 없어서"가 아니라 **"모르는 단어가 나와서"**다.
낯선 지명을 만나는 순간 → 이게 어디지? → 검색하거나 그냥 넘어감 → 둘 다 집중이 깨짐.

즉 해결해야 할 것은 *지도를 보여주는 것*이 아니라 **읽기를 멈추지 않게 하는 것**이다.

## 기존 앱과의 차이

사전조사 기록: "실제 지도 상에 위치 표시해주는 앱은 여러개 존재"

기존 앱들의 공통 구조는 **지도가 주인공**이다. 지도 화면에 핀이 찍히고, 사용자가
지도를 보러 들어간다. 읽다가 지도 앱으로 넘어가는 순간 이미 읽기는 끊긴 것이다.

Antilego의 구조는 반대다. **본문이 주인공이고 지도는 각주**다.
- 지명에 밑줄 → 탭하면 문단 옆/아래에 작은 지도가 펼쳐짐
- 읽던 자리를 벗어나지 않음
- 지도는 "지금 이 장면"만 보여줌 (전체 팔레스타인 지도가 아니라)

## "단순하고 보기 귀여운"의 해석

실제 위성/도로 지도는 이 용도에 오히려 방해다. 기원전 지명에 현대 국경과 고속도로가
같이 보이는 건 정보가 아니라 노이즈다.

→ **양식화된 일러스트 맵**(SVG)으로 간다. 지형은 단순화된 해안선·강·산 정도만,
색은 몇 가지로 제한. 이게 "귀여운 UI"이자 동시에 기존 앱과의 실질적 차별점이다.
