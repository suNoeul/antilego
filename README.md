# Antilego

성경을 읽다가 낯선 지명에서 멈추지 않게 하는 읽기 도구.

본문이 주인공이고 지도는 각주다. 지명을 탭하면 읽던 자리에서 작은 양식화 지도가
펼쳐진다 — 지도 앱으로 넘어가지 않는다.

## 이름에 대하여

그리스어 ἀντιλέγω (antilegō) = ἀντί(대항하여) + λέγω(말하다) → "반박하다", "자기모순".
프로젝트 내용과는 무관한, 그냥 마음에 든 단어. (노션 `아이디어 / Antilego Project`의
찬양 프로젝트 기록과는 별개)
